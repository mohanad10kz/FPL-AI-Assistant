# 09 - telegram_notifier.py

## الهدف من هذا الملف
إرسال نص التقرير النهائي (من `report_builder.py`) للمستخدم عبر Telegram Bot API. **هذا هو نقطة الخروج الوحيدة للمشروع تجاه المستخدم** — لا يوجد أي قناة إشعار أخرى بالنسخة الحالية.

## الارتباط بباقي الملفات
- يستقبل النص الجاهز من `report_builder.py` فقط (لا يبني أي نص بنفسه — فصل المسؤوليات: هذا الملف مسؤول فقط عن آلية "الإرسال"، وليس "المحتوى").
- يُستدعى من `main.py` كخطوة أخيرة بتسلسل التشغيل.

## إعداد البوت (خطوات يدوية لمرة واحدة — تُشرح بـ README.md وليست كوداً)
1. فتح محادثة مع `@BotFather` بتيليجرام.
2. إرسال `/newbot` واتباع التعليمات (اسم للبوت + username ينتهي بـ`bot`).
3. BotFather يُرجع `TELEGRAM_BOT_TOKEN` — يُحفظ بـ GitHub Secrets، لا يُكتب بالكود أبداً.
4. إرسال أي رسالة (مثال: "hi") للبوت الجديد من حساب المستخدم الشخصي.
5. زيارة `https://api.telegram.org/bot<TOKEN>/getUpdates` بالمتصفح لاستخراج `chat_id` من الرد (حقل `message.chat.id`).

## خطوات التنفيذ

### 1. `send_report(bot_token, chat_id, message_text)`
```
POST https://api.telegram.org/bot{bot_token}/sendMessage
Body: {"chat_id": chat_id, "text": message_text, "parse_mode": "Markdown"}
```

### 2. معالجة حدود طول الرسالة
Telegram Bot API له حد أقصى 4096 حرف لكل رسالة. **إلزامي:** تحقق من طول النص قبل الإرسال — لو تجاوز الحد، قسّمه لعدة رسائل متتالية بدل فشل الإرسال بصمت (مثال: أرسل قسم "التحويلات" برسالة، وقسم "الكابتن والرقاقة" برسالة ثانية).

### 3. معالجة فشل الإرسال
لو فشل الطلب (token خاطئ، chat_id خاطئ، مشكلة شبكة)، **لا يجب أن يفشل البرنامج بصمت.** سجّل الخطأ بوضوح بمخرجات GitHub Actions (`print` كافٍ، يظهر بسجل الـ workflow) حتى يلاحظ المستخدم أن التقرير لم يصله ويتحقق يدوياً.

### 4. رسالة اختبار منفصلة (لأول إعداد فقط)
أضف دالة بسيطة `send_test_message()` يمكن للمستخدم تشغيلها يدوياً أول مرة للتأكد أن الإعداد صحيح قبل الاعتماد على الجدولة الأسبوعية.

## معايير القبول
- [ ] رسالة اختبار تصل فعلياً لحساب تيليجرام المستخدم (اختبار يدوي حقيقي، ليس محاكاة).
- [ ] رسالة تتجاوز 4096 حرف تُقسَّم تلقائياً وتصل كاملة دون قطع أو فقدان محتوى.
- [ ] فشل الإرسال يُسجَّل بوضوح بمخرجات التشغيل ولا يوقف باقي الكود بصمت.
